# CONGRESS.IQ

美國國會動態暨台美關係情報分析平台。

## 立即檢視

直接開啟 `index.html`。本頁是可操作的前端儀表板，尚未串接即時新聞；它會明確顯示資料缺口，不會假造國會動態。

## 資料來源

Congress.gov、GovInfo、美國參眾兩院與相關委員會官方網站。

## 後續部署

GitHub Pages 可提供靜態網站；法案同步、每小時更新、AI 摘要及推播需要額外後端與合法資料來源。勿將 API keys 或內部紀錄提交到公開儲存庫。

## 完整後端原型

先前提供的 `congress-iq-github-ready.zip` 包含後端原型、API 與同步程式，建議部署時逐步合併並設定環境變數。
